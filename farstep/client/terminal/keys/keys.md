# keys

## keys

Use a single printable Unicode character or a named key: Enter, Tab, Escape,
Backspace, Space, navigation, function keys, KP_/Keypad/Numpad keys, locks,
PrintScreen, Pause, Menu, media/volume, or left/right modifier keys.

Combine Shift, Alt/Option, Ctrl/Control, Super/Cmd/Command/Win, Hyper, Meta,
CapsLock, and NumLock in any order. Names are case-insensitive. Write a literal
`+` as `+` or Plus. Alt++ also works.

Extended combinations require the application's Kitty or xterm modifyOtherKeys
mode. Unsupported chords are rejected, not approximated
