# sky

## instructions

Call helper.handshake, then sky.prepare with a provisioning budget of up to
{{MINUTES}} minutes. js and js_reset control this machine's persistent Sky
kernel. Each connection owns independent bindings. Code and input are never
automatically retried. sky.file.read and sky.file.write exchange bounded files
with SHA-256 verification and destination compare-and-swap

Read skyBackend from the handshake and sky.reference for the selected API.
upstream uses the bundled cua interface. wayland exposes the narrower Farstep
bridge through (await import("@oai/sky")).sky. The reference describes that
backend's supported methods. Do not assume app/window targeting on Wayland.
