# Skylight API reference

Source: {{referencePath}}

Follow cua's documentation for the selected app. cua_repl here means
{{skylightTool}}. Use CUA's bound app methods for selection, observations and
ordinary input. The Sky reference also covers methods outside that interface,
including clipboard handles, held keys and drag handles. Use the bundled
@oai/sky API for those methods and finish held input in finally blocks.
