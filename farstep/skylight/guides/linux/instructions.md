# Control Linux apps with Skylight

Use Skylight for Linux UI when a dedicated API or CLI does not suffice. Call
{{guideTool}} with {{startGuide}} first. Its Node REPL has persistent bindings.
For Wayland monitor captures, display images with
`await nodeRepl.emitImage(shot.bytes)` and text with `nodeRepl.write`. CUA
observations for browsers and X11 apps emit output automatically. The selected
target's guide identifies its backend and supported API. Honor the user's
permissions and app-access policy. Capture after actions and inspect after
uncertain input.
