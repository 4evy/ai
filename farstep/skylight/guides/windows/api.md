# Skylight API reference

Source: {{referencePath}}

Before using this reference, call {{guideTool}} with {{startGuide}}. Follow
cua's returned Windows documentation for the selected app. `cua_repl` here
means {{skylightTool}}. The shared reference includes options for other
platforms. Windows screenshots display automatically, scrolling takes a point
and `{ pixels }`, and paste supports plain text only. `selectText` and held
input are unavailable.

Use CUA's bound app methods for selection, observations and ordinary input. The
Sky reference also covers native window discovery, activation and rehydration.
Use its returned window objects and screenshot identifiers for raw Sky calls.
