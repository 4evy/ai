# Choose the tool for the task

Use {{runTool}} with no `target` for local commands or a saved connection ID for
SSH. Read "connect" to obtain one. Both need Farstep. Use native file tools
locally and {{readTool}}, {{writeTool}}, {{editTool}} or {{deleteTool}}
remotely.

Read the topic needed next:

- "run" for environments, TypeScript scripts and batches
- "jobs" for output and recovery
- "interactive" for terminal input
- "files" for remote file access
- "scratch" for temporary work
- "coordination" for shared work
- "helper" for installation or maintenance
- "sudo" for privileged commands
- "desktop" for Linux, macOS or Windows GUI access
