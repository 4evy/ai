# Choose the tool for the task

Use {{runTool}} with no target for local commands or a saved connection ID for
SSH; read "connect" to obtain one. Both need farstep. Use native file tools
locally and {{readTool}}/{{writeTool}}/{{editTool}}/{{deleteTool}} remotely.

Read "run" for environments, TypeScript scripts and batches; "jobs" for output
and recovery; "interactive" for terminal input; "scratch" for temporary work;
"coordination" for shared work; "helper" for installation or maintenance; "sudo"
for privileged commands; or "desktop" for Linux, macOS or Windows GUI access.
